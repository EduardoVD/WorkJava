Atividade Prática das Estruturas de Dados Pilha e Fila em Java

Aluno: Eduardo Vedana Danielli

Trabalho acadêmico desenvolvido para a Famper, com o objetivo de demonstrar de forma prática e simples o funcionamento das estruturas de dados Pilha e Fila em Java.

Pilha (Stack): É uma estrutura de dados linear que segue o princípio LIFO (Last In, First Out - Último a Entrar, Primeiro a Sair). Isso significa que o último elemento adicionado à estrutura será obrigatoriamente o primeiro a ser removido.

Fila (Queue): É uma estrutura de dados linear que segue o princípio FIFO (First In, First Out - Primeiro a Entrar, Primeiro a Sair). Isso significa que o primeiro elemento que entrou na estrutura será o primeiro a ser removido.

Para compilar e executar o projeto, primeiro certifique-se de ter o JDK (Java Development Kit) instalado em sua máquina. Em seguida, faça o clone do repositório para o seu computador utilizando o comando git clone https://github.com/EduardoVD/WorkJava. Com os arquivos baixados, abra o terminal e navegue até a pasta onde os arquivos .java estão localizados. Compile as três classes juntas executando javac Main.java Pilha.java Fila.java. Por fim, rode o programa iniciando a classe principal com o comando java Main.

_Practical Activity on Stack and Queue Data Structures in Java_

_Student: Eduardo Vedana Danielli_

_Academic work developed for Famper, with the objective of demonstrating in a practical and simple way the functioning of the Stack and Queue data structures in Java._

_Stack: It is a linear data structure that follows the LIFO (Last In, First Out) principle. This means that the last element added to the structure will necessarily be the first to be removed._

_Queue: It is a linear data structure that follows the FIFO (First In, First Out) principle. This means that the first element that entered the structure will be the first to be removed._

_To compile and run the project, first make sure you have the JDK (Java Development Kit) installed on your machine. Then, clone the repository to your computer using the command git clone https://github.com/EduardoVD/WorkJava. With the files downloaded, open the terminal and navigate to the folder where the .java files are located. Compile the three classes together by running javac Main.java Pilha.java Fila.java. Finally, run the program by starting the main class with the command java Main._
